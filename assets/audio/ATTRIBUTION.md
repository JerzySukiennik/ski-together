# Sound credits

Every sound the game plays lives in this folder, so the game works with no
network at all. These are the files that came from somebody else, what their
licence is, and where they came from. They are aggregated here as separate
files — none of them is modified, and none of them is merged into anything —
so each keeps its own licence and the game's own code keeps its own.
